# Общие настройки

Вкладка **Службы → Okop → Настройки**. В скобках указано имя опции в `/etc/config/okop` (секция `settings`) на случай правки через `uci` или файл.

## DNS

- **Тип протокола DNS** (`dns_type`): `udp`, `dot` (DNS over TLS) или `doh` (DNS over HTTPS). В стандартном конфиге — `udp`.
- **DNS-сервер** (`dns_server`): через него sing-box резолвит домены, которых нет в списках. Можно выбрать из списка или ввести свой: IP (`8.8.8.8`), имя хоста (`dns.adguard-dns.com`) или имя с путём для DoH (`dns.example.com/dns-query`). В стандартном конфиге — `77.88.8.8`.
- **Bootstrap DNS-сервер** (`bootstrap_dns_server`): нужен, когда DNS-сервер задан именем хоста. Через bootstrap-сервер sing-box узнаёт IP самого DNS-сервера. Указывается IP, по умолчанию `77.88.8.8`.
- **DNS Rewrite TTL** (`dns_rewrite_ttl`): TTL в секундах для ответов с fake-IP, по умолчанию 60. Чем меньше значение, тем быстрее устройства замечают изменения в списках, но тем чаще отправляют DNS-запросы.

## Интерфейсы

- **Исходный сетевой интерфейс** (`source_network_interfaces`): трафик с каких интерфейсов перехватывать. По умолчанию `br-lan`. Беспроводные интерфейсы выбрать нельзя: они входят в мост `br-lan`. Если есть отдельная сеть, например гостевая, добавьте её мост.
- **Выходной сетевой интерфейс** (`enable_output_network_interface`, `output_network_interface`): через какой интерфейс sing-box отправляет прямой трафик. По умолчанию определяется автоматически. Задавайте вручную, только если WAN-интерфейсов несколько.

  Сам Okop смотрит только на `output_network_interface`: флаг `enable_output_network_interface` влияет лишь на то, показывает ли LuCI это поле. При правке через `uci` удалите `output_network_interface`, чтобы вернуть автоопределение.
- **Мониторинг интерфейсов** (`enable_badwan_interface_monitoring`, `badwan_monitored_interfaces`, `badwan_reload_delay`): перезапускать Okop, когда выбранные WAN-интерфейсы поднимаются, например после переподключения PPPoE. Задержка перед перезапуском указывается в миллисекундах, по умолчанию 2000.

## Маршрутизация

- **Отключить QUIC** (`disable_quic`): блокировать QUIC (HTTP/3 поверх UDP) у перехватываемого трафика. Браузеры и приложения переключаются на обычный TCP. Помогает, если через прокси плохо работает видео, например YouTube.
- **Исключить NTP** (`exclude_ntp`): не перехватывать синхронизацию времени (UDP, порт 123), чтобы она всегда шла напрямую.
- **Исключённые из маршрутизации IP** (`routing_excluded_ips`): устройства в LAN, чей трафик всегда идёт напрямую, мимо всех секций.

## Списки

- **Частота обновления списков** (`update_interval`): раз в час, 3 часа, 12 часов, день (по умолчанию) или 3 дня. Кроме того, списки обновляются при каждом старте Okop.
- **Скачивать списки через Proxy/VPN** (`download_lists_via_proxy`, `download_lists_via_proxy_section`): загружать все списки через выбранную секцию. Нужно, если GitHub у провайдера недоступен или работает плохо.
- **Скачивать списки напрямую, если Proxy/VPN не работает** (`download_lists_direct_fallback`): если через выбранную секцию скачать не удалось, попробовать без неё. По умолчанию выключено, и списки качаются только через секцию. Включайте, если важнее получить свежие списки, чем скрыть обращения к GitHub.
- **Путь хранения списков** (`ruleset_cache_path`): где хранить скачанные `.srs`- и `.json`-списки. По умолчанию `/etc/okop/rulesets` на флеше, и списки переживают перезагрузку. В оперативной памяти (`/tmp/okop/rulesets`) после каждой перезагрузки списки будут пустыми, пока не скачаются заново. Не указывайте `/tmp/sing-box/rulesets`: этот каталог Okop очищает при остановке.

## DHCP

- **Не трогать мой DHCP!** (`dont_touch_dhcp`): Okop не будет менять настройки dnsmasq. Тогда направить DNS в sing-box (`127.0.0.42`) нужно самостоятельно, а [защита DNS](how-it-works.md#защита-dns) не работает. Включайте, если DNS в сети устроен нестандартно, например через AdGuard Home.

## Dashboard (YACD)

- **Включить YACD** (`enable_yacd`): веб-интерфейс Clash API по адресу `http://<адрес роутера>:9090/ui`. В нём видны соединения и можно переключать серверы в секциях Selector и URLTest. Вкладка **Dashboard** в LuCI работает и без этой опции.
- **Доступ к YACD из WAN** (`enable_yacd_wan_access`, `yacd_secret_key`): открыть интерфейс снаружи с паролем. Порт в firewall нужно открыть самостоятельно.

## Служебное

Меняйте, только если понимаете зачем:

- **Путь к конфигу** (`config_path`): где хранится конфиг sing-box, `/etc/sing-box/config.json` (флеш, по умолчанию) или `/tmp/sing-box/config.json` (память).
- **Путь к файлу кэша** (`cache_path`): кэш sing-box с таблицей fake-IP. По умолчанию в памяти (`/tmp/sing-box/cache.db`). На флеше таблица сохраняется между перезагрузками, но запись идёт часто.
- **Уровень логирования** (`log_level`): подробность логов sing-box, по умолчанию `warn`. Для поиска проблем временно ставьте `info` или `debug`.
