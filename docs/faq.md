# Вопросы и рецепты

## Маршрутизация

**Как вывести один сайт из большого списка?** Создайте секцию типа **Exclusion** и добавьте домен в её пользовательский список. Exclusion срабатывает раньше секций Proxy и VPN.

**Как пустить один сервис из `russia_inside` через другой туннель?** Секции Proxy и VPN проверяются по порядку, и срабатывает первая. Поэтому можно создать отдельную секцию с нужным сервисом (например, `youtube` через VPN) и поставить её выше секции с `russia_inside`. Другой вариант — отказаться от `russia_inside` и собрать нужные сервисы из отдельных списков по разным секциям.

**Как пустить весь трафик одного устройства через туннель?** Добавьте его IP в **Fully Routed IPs** нужной секции. Чтобы IP не менялся, закрепите его в **Сеть → DHCP и DNS → Статические аренды**.

**Как исключить устройство из маршрутизации?** Добавьте его IP в **Исключённые из маршрутизации IP** в [настройках](settings.md#маршрутизация).

**Как заблокировать сайты?** Секция типа **Block** со списками, например `porn`, или со своими доменами.

**Гостевая сеть.** Если гостевая сеть в отдельном мосту (например, `br-guest`) и этого моста нет в **Исходном сетевом интерфейсе**, Okop её не затрагивает. Чтобы гостевые устройства тоже шли через Okop, добавьте мост в этот список и разрешите гостевой зоне firewall обращаться к роутеру за DNS.

**Звонки в Telegram, WhatsApp, Discord не работают.** Добавьте списки `telegram`, `meta`, `discord`: в них есть подсети, через которые идут звонки. В мессенджерах, где это можно, отключите звонки peer-to-peer. Собеседник тоже должен быть в сети, где эти сервисы доступны.

## Прокси

**Поддерживаются ли подписки?** Нет. Добавьте ссылки из подписки по отдельности — в секцию URLTest или Selector.

**Какие ссылки поддерживаются?** `vless://`, `ss://`, `trojan://`, `socks4://`, `socks5://`, `hy2://`, `hysteria2://`. Примеры — в [String-example.md](../String-example.md). Для остального используйте **Outbound Config** — готовый outbound sing-box в JSON, его можно экспортировать из NekoBox/Nekoray.

**Как выбрать сервер вручную в секции URLTest?** На вкладке **Dashboard** нажмите на нужный сервер, автовыбор при этом отключится. Вернуть его можно, выбрав «Самый быстрый». Выбор хранится в кэше sing-box: при кэше в памяти (по умолчанию, см. `cache_path` в [settings.md](settings.md#служебное)) после перезагрузки роутера снова включится автовыбор.

## Установка и обновление

**Не хватает места для sing-box.** Можно поставить урезанную сборку без поддержки Tailscale, она экономит 5–10 МБ:
```
opkg remove sing-box --force-depends
opkg install sing-box-tiny
```

**Как обновить sing-box вручную?**
```
service okop stop
opkg update && opkg upgrade sing-box
service okop start
```

**Как откатиться на предыдущую версию?** Скачайте пакеты нужной версии со [страницы релизов](https://github.com/trahelman/okop/releases) и установите их вручную (см. [install.md](install.md#установка-вручную)).

**Установщик пишет `Operation not permitted` или не может скачать файлы.** Проверьте время на роутере (`date`) — при неверном времени не работает HTTPS. Синхронизировать: `ntpd -q -p 194.190.168.1`. Проверьте DNS: `nslookup downloads.openwrt.org`.

## Сторонние прошивки

Okop проверяется на стандартной OpenWrt. На других сборках известны проблемы:

- **GL.iNet (прошивки на базе OpenWrt 24.10).** Служба `vpn-client` добавляет свои правила маркировки трафика, которые конфликтуют с Okop. Отключите её.
- **Сборки без nftables.** Okop на них работать не будет.
- **Сборки с предустановленными `https-dns-proxy`, `nextdns` или старым Podkop.** Удалите эти пакеты перед установкой.
- **Сборки со старыми правилами iptables** (`iptables-mod-extra`). Могут мешать работе tproxy.
