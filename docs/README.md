# Документация Okop

Okop — маршрутизация трафика для OpenWrt на базе sing-box: нужные сайты и сервисы идут через прокси или VPN, остальное — напрямую. Okop — форк [Podkop](https://github.com/itdoginfo/podkop). Чем он отличается, описано в [differences.md](differences.md).

## Начало работы

- [Установка](install.md) — требования, установка и обновление, переход с Podkop, удаление.
- [Как это устроено](how-it-works.md) — путь DNS-запроса, fake-IP, списки и их хранение, защита DNS.

## Настройка

- [Секции](sections.md) — что маршрутизировать: списки доменов и подсетей, порядок правил.
- [Подключения](connections.md) — через что: прокси, VPN-интерфейсы, группы с резервом и выбором самого быстрого.
- [Общие настройки](settings.md) — DNS, интерфейсы, обновление списков, DHCP, Dashboard.
- [DNS](dns.md) — DNS на устройствах, выбор DNS-сервера, AdGuard Home, ручная настройка dnsmasq.
- [Туннели](tunnels.md) — WireGuard, AmneziaWG, OpenVPN и OpenConnect для подключений-интерфейсов.
