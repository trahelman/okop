# Okop

Маршрутизация трафика для OpenWrt.

Направляйте нужные ресурсы в туннель, а остальное — напрямую. Открытое программное обеспечение на базе [sing-box](https://github.com/SagerNet/sing-box).

Okop — форк проекта [Podkop](https://github.com/itdoginfo/podkop) с исправлениями ошибок. Подробнее о происхождении — в [NOTICE](NOTICE).

> [!WARNING]
> Проект находится в стадии бета-версии. Возможны ошибки, нестабильная работа и существенные изменения функциональности.

> [!NOTE]
> Okop разрабатывается с помощью ИИ: большая часть кода, тестов и документации написана ИИ-ассистентом (Claude Code) под руководством автора. Изменения проверяются в [тестовой среде](dev/README.md), но учитывайте это и проверяйте поведение на своём оборудовании.

# Отличия от Podkop

- **sing-box запускается, даже если списки не скачиваются.** Okop сам скачивает списки и хранит их в `/etc/okop/rulesets`, поэтому выключенный VPN или прокси больше не роняет sing-box и DNS во всей сети.
- **Защита DNS.** Если sing-box не отвечает, dnsmasq временно возвращается на обычные DNS-серверы, и интернет в сети продолжает работать.
- **Настройки dnsmasq сохраняются.** Перенаправления DNS для отдельных доменов работают и при включённом Okop, а после его остановки все настройки восстанавливаются в точности.
- **Скачивание списков через прокси работает.** Прямое скачивание, если прокси недоступен, — отдельная настройка.
- **Переход с Podkop автоматический:** установочный скрипт удаляет Podkop и переносит его настройки.

Подробнее — в [docs/differences.md](docs/differences.md).

# Вещи, которые необходимо знать перед установкой

### Обновления и конфигурация
- После обновления очищайте кэш браузера для интерфейса LuCI.
- После обновления проверяйте конфигурацию — она может изменяться между версиями.
- При старте Okop модифицируется конфигурация Dnsmasq.
- Okop изменяет конфигурацию sing-box. Если вы используете собственную конфигурацию, заранее сохраните её.

### Системные требования
- Требуется OpenWrt 24.10 или выше.
- Необходимо минимум 25 МБ свободного места на устройстве. Устройства с флеш-памятью 16 МБ не поддерживаются.

### Важные ограничения и особенности
- Okop и Podkop не могут быть установлены одновременно. Установочный скрипт удаляет Podkop и переносит его конфигурацию в `/etc/config/okop`.
- Если установлен Getdomains, его [необходимо удалить](https://github.com/itdoginfo/domain-routing-openwrt?tab=readme-ov-file#скрипт-для-удаления).
- Dashboard доступен только при подключении по HTTP (из-за особенностей Clash API). При использовании HTTPS или домена работа может быть недоступна.

### Поддержка
- При возникновении проблем создавайте [GitHub Issues](https://github.com/trahelman/okop/issues).

# Установка

Для установки и обновления достаточно выполнить один скрипт:
```

```
